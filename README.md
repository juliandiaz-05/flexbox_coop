# Proyecto Flexbox 

Proyecto de maquetación web utilizando **Flexbox** y metodología **BEM** (Block Element Modifier).

## Integrantes

- Julian Diaz
- Sara Estupiñan
- Haziel Solano

## Tecnologías

- HTML5
- CSS3 (Flexbox)
- Metodología BEM

## Estructura del proyecto

```
flexbox/
├── index.html
├── css/
│   └── styles.css
└── resources/
    └── img/
```

## Componentes

1. Barra de navegación horizontal
2. Tarjeta de producto
3. Galería de imágenes
4. Formulario de contacto
5. Encabezado de sección
6. Lista de tareas
7. Componente de testimonial
8. Footer con tres columnas
9. Sección de precios
10. Sidebar de navegación
